# Legacy artwork

Earlier artwork is preserved here for reference and future reuse.

- `root/`: PNG files that previously sat beside the GDevelop project.
- `imports/`: loose frames/textures previously stored directly inside `assets/`.

Current generated artwork stays in the named asset-pack folders above this directory. Import any legacy image through GDevelop if you want to use it again. Retained resource aliases were updated to these paths during the cleanup; no image bytes were changed.
