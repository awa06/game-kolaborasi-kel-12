# Animal Hunter UI generation

Mode: built-in image generation, followed by cell extraction and nearest-neighbor sizing.

## Title logo

Use case: stylized-concept. Create a polished transparent PNG game TITLE LOGO for an original colorful 16-bit pixel-art tropical cowboy platformer. Exact title text in TWO centered lines: top line "ANIMAL", bottom line "HUNTER". Correct spelling essential. Bold chunky golden ivory pixel lettering with dark brown outline and warm amber inset shadow, extremely legible at game menu size. Title mounted on a weathered dark walnut wooden sign with clipped corners, brass studs, light rope detailing, small brown cowboy hat resting at upper left, a tiny red scarf draped along lower right and small green tropical leaves at corners. Rich pixel clusters, clean silhouette, crisp pixelated edges. Wide composition about 2.2:1, logo fits entire image with generous transparent margin. This is a standalone title asset, NOT a screenshot or a full menu. Real alpha transparency outside the wooden sign. No backdrop, no watermarks, no extra text, no subtitles, no UI buttons, no ground shadow. Match the charming brown-hat red-scarf cowboy pixel-art assets in the project.

## Icons

Use case: stylized-concept. Actual transparent pixel-art game UI ICON ATLAS for Animal Hunter, a colorful tropical cowboy platformer. EXACTLY 8 isolated icons in a regular FOUR columns by TWO rows grid. Wide canvas about 2:1. Every cell equal square size, each icon centered with at least 15 percent transparent padding on every side. Must stay completely within its own cell. Crisp rich 16-bit pixel clusters, chunky brass-gold rim, dark emerald interiors, warm brown outlines matching existing round play/pause/replay buttons. ROW ONE left to right: (1) HOME button, circular brass-rimmed emerald button with clear small cream house silhouette; (2) EXIT button, same circular button with cream doorway and arrow pointing outward; (3) CREDITS button, same circular button with cream parchment scroll and small quill; (4) TROPHY emblem, golden trophy cup with two laurel leaves and emerald gem, no button frame. ROW TWO left to right: (1) GAME OVER emblem, stylized non-gory ivory skull with small cowboy hat and crossed brass revolvers behind it, charming rather than scary; (2) KEY icon, brass key with emerald gem, no button frame; (3) SCORE icon, brown pouch with gold coins spilling out, no button frame; (4) HELP button, circular brass-rimmed emerald button with a single cream question-mark symbol. True transparent alpha background. No wording, letters, captions, labels, borders or drawn grid. No UI screenshot, no scenery, no ground shadows. Essential: 4 columns, 2 rows, all eight separately extractable.
